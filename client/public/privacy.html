FORTIFY FIELD NOTES

Privacy Policy

Fortify is designed to analyze passwords locally. This policy covers the Fortify web app and the Fortify Lens Chrome extension.

Plain-language summary. Passwords typed into the extension or strength checker are analyzed locally and are not transmitted or stored. The extension stores only a user-selected companion-site URL in Chrome storage. Any connection to the companion app is initiated by the user.

Information handled

  • The extension processes entered password text locally to calculate a strength result. It does not send that password to Fortify or another party.
  • Chrome storage retains the user-configured Fortify companion URL so the extension can open or, after the user grants optional access, communicate with that chosen site.
  • If a signed-in user explicitly saves a sanitized assessment, the companion app receives only the attacker model, strength label, score, and entropy estimate. The password and pattern details are excluded.
  • The optional Fortify vault stores browser-encrypted ciphertext, IV, salt, and encryption-version marker. The vault passphrase and decrypted entry contents are not sent to the service.

Use and sharing

Fortify uses handled data only to provide the described password analysis, companion-account, sanitized-report, and encrypted-vault features. Fortify does not sell data, use it for advertising, or collect browsing history. It does not permit human review of password content.

Security and user choice

Companion connections use HTTPS. The Chrome extension asks for optional access only after the user chooses a published Fortify companion address. Users may remove the extension, revoke its site access, or delete their own saved companion records. Encrypted vault entries cannot be recovered if a user loses the local vault passphrase.

Contact and changes

Questions about Fortify privacy can be sent to the contact address shown on the Chrome Web Store listing. This policy will be updated when data practices change.
